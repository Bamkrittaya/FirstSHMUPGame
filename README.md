# 😇🧙 Angel & Witches — First SHMUP Game (Unity)

**Angel & Witches** is a cheerful, magical **SHMUP (shoot 'em up)** game where you play as a kind-hearted angel on a mission to **purify witches** and defeat bats in a dreamy purple night sky.  
Instead of violence, the core theme is **turning villains into good beings using heart magic** 💖✨

## ✨ Features

- 💖 **Heart projectile shooting**
- 🧙 **Purify witches** (evil → good transformation theme)
- 🦇 **Bats as extra enemies**
- ☠️ Dodge enemy **poison attacks**
- ❤️ **3 lives/3 hearts health system**
- 🏆 Score + high score tracking
- 🌙 Dreamy **purple magical night sky** atmosphere

## 🎮 How To Play

### Controls

| Action | Key |
|-------|-----|
| Move | `WASD` / Arrow keys |
| Move Faster | Hold `Shift` |
| Shoot Heart Projectile | `Space` |
| Pause | `ESC` |

---

## 🧠 Gameplay Objective

Your goal is to achieve the **highest score** by:

- Shooting **hearts** to damage and purify witches
- Destroying bats for extra points
- Avoiding poison projectiles and enemy collisions
- Surviving with only **3 hearts/lives**

Scoring system:
- 🧙 Witch = **100 points**
- 🦇 Bat = **50 points**
